# SleepBlocker - Prevent your PC from timing out!
---
### USAGE:
When you start the file, the application will run in the background and prevent your computer from entering sleep mode.
A tray icon will appear near the Windows clock. Clicking it will open the [usage](https://sleep-blocker.netlify.app/usage) page.
Right-click the tray icon to access controls. You can pause, resume, or quit the sleep blocking process.
When paused, Sleep Blocker remembers the exact moment it stopped, and continues from that point when resumed.
You can keep Sleep Blocker running when you need your computer to stay awake, such as during downloads, long tasks, or background operations.
